# Changelog

## 0.1.0

### Features

- First release: an HTTP Deployment and Service for stateless apps on any runtime, with
  workers, CronJobs, pre/post-deploy hooks, Ingress, HPA, PodDisruptionBudget, optional
  metrics Service and ServiceMonitor, and the Node-only `NODE_OPTIONS` memory helper.
  Values follow the Laravel chart 0.7 layout.
